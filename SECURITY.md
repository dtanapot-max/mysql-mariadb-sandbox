# Security

This project is a browser/JavaScript database **simulation sandbox**. It is not a security boundary and must not be treated as a replacement for database authorization, server isolation, or production access controls.

Do not put production credentials, secrets, or sensitive production datasets into public test evidence or GitHub Pages.

For security reports, open a GitHub issue only when disclosure is safe. For sensitive reports, use the repository owner's private contact/security reporting channel if one is enabled on GitHub.
